# Étude 02 — Dynamique des régimes : pré-enregistrement
*Déposé le 13 octobre 2026, avant toute analyse · auteur : Bran Brière · [English version](02-regimes-preregistration.en.md)*

La date de ce fichier dans l'historique du dépôt fait foi : la règle ci-dessous a été fixée avant de regarder les données.

## Question

Quels états observables du pays précèdent un changement de pouvoir (révolution, coup de palais, défaite électorale, vacance) ?

## Règle de séparation des données

| Période | Usage |
| --- | --- |
| 9 octobre 2026 – 8 janvier 2027 (ère 1, 3 premiers mois) | **Exploration :** on peut regarder les données et formuler des hypothèses. |
| À partir du 9 janvier 2027 (au moins 3 mois) | **Test :** les hypothèses, figées avant cette date, sont évaluées sur ces mois jamais regardés pour les construire. |

## Engagements

1. Les hypothèses et leur indicateur de réussite seront ajoutés à ce dossier, dans un fichier daté, **avant le 9 janvier 2027**. Aucune hypothèse ajoutée après ne pourra être présentée comme testée.
2. Les données de la période de test ne seront ni tracées ni résumées avant que les hypothèses soient figées.
3. Les changements de firmware pendant les deux périodes seront listés ; leur effet possible sera discuté dans les limites.
4. Si le pays change d'ère (RESET), la règle s'applique séparément à chaque ère.
5. Le résultat sera publié quel qu'il soit, y compris s'il est négatif ou non concluant.

## Limites connues dès maintenant

Un seul pays réel : les citoyens ne sont pas des expériences indépendantes. Les règles politiques sont écrites dans le code ; une régularité qui découle directement d'une règle n'est pas une découverte. Les simulations sur ordinateur serviront de référence.
